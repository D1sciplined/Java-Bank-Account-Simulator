
# Java Bank Account Simulator

A Java console application I developed for CSC 223 at Northern Virginia Community College. The program allows users to deposit money, withdraw funds, and check their account balance while preventing invalid transactions.

## Features

- Deposit and withdraw funds
- Check account balances
- Prevent withdrawals that exceed available funds
- Reject invalid deposit and withdrawal amounts
- Handle transaction errors using custom Java exceptions
- Navigate an interactive menu

## Technologies Used

- Java
- Object-Oriented Programming
- Exception Handling
- Eclipse IDE

## How to Run

1. Download the repository.
2. Open Eclipse and create a Java project.
3. Copy the files from `src/Module1` into a package named `Module1`.
4. Run `TesterExceptionsBankAccount.java` as a Java Application.
5. Follow the console menu to perform transactions.

## Testing

I tested deposits, withdrawals, balance inquiries, insufficient funds, and negative transaction amounts. Valid transactions updated the balance correctly, while invalid transactions were rejected without changing the balance.

## Project Background

I developed this project to apply Java programming concepts, particularly object-oriented programming and exception handling, to a practical banking simulation.
